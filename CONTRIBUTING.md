# Contributing

1. Keep your work on your assigned member branch. Member 4 uses `member4-serving-dashboard`.
2. Use conventional commits (`feat:`, `fix:`, `test:`, `docs:`).
3. Run `pytest -q` and `ruff check src tests` before pushing when the shared project environment is available.
4. Open a pull request to `main`; one reviewer from another member is required.

See `docs/GIT_WORKFLOW.md` and `TEAM_OWNERSHIP.md` for the team's contribution and ownership guidelines.
